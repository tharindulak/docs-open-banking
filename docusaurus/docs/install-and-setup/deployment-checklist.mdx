# Deployment Checklist

When deploying WSO2 Open Banking in a production server, make sure to go through the following checklists to guide you in setting up your production environment.

- For the WSO2 Open Banking Identity Server Accelerator, see the [WSO2 Identity Server Deployment Checklist](/identity/deploy/deployment-checklist/).
- For the WSO2 Open Banking API Manager Accelerator, see the [WSO2 API Manager Deployment Checklist](/api-platform/api-manager/install-and-setup/setup/deployment-best-practices/production-deployment-guidelines/).
