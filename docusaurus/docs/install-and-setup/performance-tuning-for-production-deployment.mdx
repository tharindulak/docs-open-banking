# Performance Tuning for Production Deployment

When deploying WSO2 Open Banking in a production server, make sure to go through the following performance tuning recommendations to optimize your production environment.

- For the WSO2 Open Banking Identity Server Accelerator, see [Performance Tuning Recommendations](https://is.docs.wso2.com/en/latest/deploy/performance/performance-tuning-recommendations/) in the WSO2 Identity Server documentation.
- For the WSO2 Open Banking API Manager Accelerator, see [API-M Performance Tuning](https://apim.docs.wso2.com/en/latest/install-and-setup/setup/deployment-best-practices/tuning-performance/) in the WSO2 API Manager documentation.
