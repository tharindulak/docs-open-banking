# Security Guidelines for Production Deployment

When deploying WSO2 Open Banking in a production server, make sure to comply with the following security guidelines.

- For the WSO2 Open Banking Identity Server Accelerator, see the [WSO2 Identity Server Security Guidelines for Production Deployment](https://is.docs.wso2.com/en/latest/deploy/security/security-guidelines-for-production-deployment/).
- For the WSO2 Open Banking API Manager Accelerator, see the [WSO2 API Manager Security Guidelines for Production Deployment](/api-platform/api-manager/install-and-setup/setup/deployment-best-practices/security-guidelines-for-production-deployment/#api-m-runtime-security).
